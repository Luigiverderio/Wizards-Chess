# Wizards-Chess

## Português (pt-BR)

Você já quis, alguma vez, viver uma partida de xadrez mágico inspirada no universo de Harry Potter?  
Este projeto traz essa ideia para o tabuleiro: estratégia, magia e diversão em cada movimento.

## English

Have you ever wanted to experience a magical chess match inspired by the Harry Potter universe?  
This project brings that idea to the board: strategy, magic, and fun in every move.
